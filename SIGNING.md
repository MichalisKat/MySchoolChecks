## Signing Policy

- Only tagged releases are signed (e.g. `v0.9.7`)
- Signing is performed by the project owner after each release
- All commits are made directly by the maintainer — no external contributors require peer review at this time
- Multi-factor authentication (MFA) is enabled on all accounts with signing access

## Software Behavior

- MySchool Checks does **not** collect any user data
- No telemetry, analytics or remote tracking of any kind
- Credentials are stored locally in the Windows Credential Manager (encrypted)
- An uninstaller is provided via the NSIS installer

## Privacy Policy

This software does not collect, transmit or store any personal data externally.
All data remains on the user's local machine.
